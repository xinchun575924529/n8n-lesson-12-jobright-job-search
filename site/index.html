What it does

A hosted n8n form collects job title, location and remote preference, calls Jobright's public visitor endpoint, and renders the top-5 US job listings on a completion page - with a dedicated error net that turns every failure into a friendly explanation page.

The 3 lessons that make it worth your hour

The shipped template is silently broken: raw body + response-format=json returns an unparsed stream on current n8n versions - every search dies with "unexpected response". One dropdown change in the HTTP node fixes it. Verified with before/after executions.
The endpoint filters non-browser clients: plain script clients get a lying 400 Invalid request body while the body is fine. One header line fixes it.
The error net pattern: onError: continueErrorOutput routing into a dedicated failure page - steal this for every customer-facing automation you ship.
